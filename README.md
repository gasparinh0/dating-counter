# 💖 Dating Counter

Um cantinho fofo para celebrar o amor todos os dias.

Este projeto é um contador de namoro feito em React para mostrar há quanto tempo **Lucas e Gaby** estão juntos, com visual romântico, música de fundo e notificação especial no dia 16 de cada mês.

## ✨ O que tem de fofo aqui?

- Contador de tempo de relacionamento
- Interface romântica com tema em tons de rosa
- Botão para tocar/pausar música ambiente
- Notificação mensal no navegador (dia 16)

## 🚀 Como rodar localmente

```bash
npm ci
npm start
```

Abra [http://localhost:3000](http://localhost:3000) no navegador.

## 🧪 Scripts disponíveis

- `npm start`: inicia o app em modo desenvolvimento
- `npm test`: roda os testes com React Scripts
- `npm run build`: gera build de produção
